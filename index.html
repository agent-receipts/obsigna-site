Obsigna

The reference implementation of the Agent Receipts protocol.

Tamper-evident, cryptographically signed audit trails for AI agent actions — Ed25519-signed, SHA-256 hash-chained records.

Obsigna implements the Agent Receipts open standard: a specification for producing verifiable, append-only records of what AI agents do, on whose behalf, and when. Every receipt is signed and chained so that no entry can be altered or removed without detection.
